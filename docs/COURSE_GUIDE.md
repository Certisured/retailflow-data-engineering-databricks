# Your course sequence

Begin with **Why Data Engineering**, then **Meet RetailFlow**, then **Trace Your First Sale**. The opening explains Excel, SQL and Databricks before asking you to build anything. Throughout, ask: what does the business need, is the answer correct, and can unnecessary work be avoided?

Day 1 totals 360 teaching minutes; Day 2 totals 360. Breaks, account preparation and initial environment setup are additional. The opening fits within L01's 45 minutes: orientation 10, Meet RetailFlow 8, practical Vibe 3, learner action 13, review 6, exit check 5.

The numbered exercise cells start blank. Supplied support code helps you focus on the learning action; it is not a requirement to write a large utility library from scratch. Notebooks are revisited in lesson order: in particular, 02-05 is used in L05 before the independent 02-04 report step in L06.

The course starts with Python/PySpark. SQL is introduced as a useful query language in the orientation; this starter does not claim to contain a complete SQL or advanced performance-tuning course. The same business-question and correctness habits apply to both languages. Runtime and cost improvements should be measured in the actual workspace rather than inferred from this small fixture.
